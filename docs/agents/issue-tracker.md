# Issue Tracker: GitHub

Issues and PRDs for this repository are tracked in GitHub Issues.

## Conventions

- Create issues with the GitHub CLI (`gh issue create`).
- Use the label vocabulary in `triage-labels.md`.
- Treat external pull requests as a contribution surface, not as issue-tracker requests.
- Link implementation pull requests to their GitHub issue.

When a skill says to publish to the issue tracker, create a GitHub issue in this repository.
